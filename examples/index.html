ice-chart 示例

ice-chart 是构建在 ice-render Canvas 引擎之上的交互式图表库：命中测试、事件派发、坐标系与脏矩形局部重绘都由引擎承担， 图表层专注在「数据 ↔ 像素 ↔ 语义事件」的映射上。

  • 基础折线 / 面积（悬停、十字准星、提示框、缩放、平移）
  • 分组与堆叠柱形（图例切换、柱形命中）
  • 横向柱状图 / 气泡图（排行榜、第三维尺寸）
  • 多 y 轴叠加（左轴成交量 + 右轴涨跌幅/换手率）
  • 饼图 / 环形图 / 玫瑰图（扇形命中、扇区图例）
  • 雷达图（多边形 / 圆形网格、顶点命中）
  • 漏斗图 / 仪表盘（阶段梯形、指针随数值转动）
  • 箱线图 / 瀑布图（五数概括、累计柱与连接线）
  • 分布组图（小提琴 / 蜂群 / 箱线叠成雨云图，密度轮廓 + 逐点避让）
  • 矩形树图（层级构成、squarified 布局）
  • 力导向关系图（无底图，可拖动节点重排）
  • 迷你 MATLAB（函数绘图：表达式、参数扫动、参数曲线、等比坐标）
  • 手写 option vs DSL（同表单图：encoding 数据绑定 + 结构化诊断）
  • 可编辑图表（自定义系列 + 数据坐标图元：注释 / 阈值线 / 预测带可拖）
  • 标注（目标线 / 阈值线 / 异常点 / 目标区间 —— 声明式、随坐标系动）
  • 动画（入场 / 更新 / 错峰 / 弹簧 / 动效偏好）
  • 实时数据流（滑动窗口追加、仪表盘 / 热力图 / 柱形跟着数据动）
  • 运营监控大屏（深色 · 12 张图 · 数据流 + 跨图联动 + 告警）
  • 设备监控大屏（青绿 · 水位球 / 拓扑 / 心跳波形）
  • 能源调度大屏（蓝紫 · 源网荷桑基 / 电量平衡瀑布 / 谐波合成）
  • 物流调度大屏（橙红 · 分拣漏斗 / 包裹流向 / 逐项配色柱形）
  • 函数实验大屏（紫 · 参数扫动 / 极坐标 / 采样密度 / 表达式诊断）
  • 大数据量（5 万点 × 3 系列，LTTB 降采样 + 二分命中）
  • 大数据量 · 引擎虚拟子源原型（列存文档 + 窗口批量落墨 + 命中即物化，50 万点 × 3 系列）
  • 无障碍（数据表镜像、aria-live 播报、键盘导航）
  • 热力图（类目 y 轴、颜色插值、单元格命中）
  • 桑基图（分层松弛布局、节点/连线命中）
  • 序列化 / 反序列化（导出 JSON、重建、逐像素比对）
  • 交互总览（框选、多选、高亮联动、键盘导航、事件日志）
  • 时间轴 + dataZoom 初始视窗
  • 跨图联动（悬停 / 缩放 / 框选三路联动）

运行前先执行 npm run build && npm run examples:prepare，然后 npm run examples:serve。
