## 文档约定

1. **文件名带序号**（`01-architecture.md` …），**每篇开头有目录**，小节一律编号（`1` / `1.1`），
   跨篇引用写「见 `02-pipeline.md` §2.3」。新增一篇时取下一个空号，并回到本页登记。
2. **数字都是实测**，并写清口径（点数、窗口、工具、脚本）。产生这些数字的尺子放在
   `scripts/`，结论记在根目录 `CHANGELOG.md`，施工图与「还剩什么」记在 `plans/`。
3. **只写结论与理由，不写出处**：调研来的做法一律内化成我们自己的规范
   （仓库纪律：不出现第三方 / 竞品项目名，见根目录 `AGENTS.md`）。
4. 改代码时**同步改这里**：文档与 `AGENTS.md` 都是维护面，不是一次性产物。
