无障碍：数据表镜像 + 实时播报

canvas 对屏幕阅读器是不可见的，所以 attachA11yMirror() 会在 canvas 旁挂一张 视觉隐藏但可读的数据表（含 caption、表头与逐行数据），并把 canvas 的 aria-describedby 指向它；同时挂一个 aria-live 区域， 你悬停或用键盘 ← → 移动数据点时，它会播报当前数据。
下方「镜像内容」是本页把同一张数据表渲染出来的样子，方便肉眼确认读屏看到的是什么。

无障碍 API
· chart.getDataTable()：结构化数据表
· chart.getA11yTree()：引擎组件树 + 逐数据点虚拟节点
· chart.attachA11yMirror() / detachA11yMirror()
· chart.announceA11y(text)：手动播报
· 键盘导航：← → ↑ ↓、Enter 选中
